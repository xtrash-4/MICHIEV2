# About You · Michie Archive

Satu halaman: pita film 3D yang bergerak mengikuti lagu "About You", dengan foto dan lirik yang berganti sesuai waktunya.

- `index.html` — halaman utamanya (Three.js + GSAP dari CDN, tanpa build)
- `about-u/` — lagu, foto, sampul, dan `sync-source.js` (waktu + lirik + foto)
- `versi-lengkap.html` — versi lama dengan menu dan halaman Info
- `ANALISA.md` — cara kerja dan pengaturan

Jalankan lokal: `python -m http.server 5178`, lalu buka http://localhost:5178.
Bisa langsung di-deploy sebagai situs statis (Vercel, Netlify, GitHub Pages).
